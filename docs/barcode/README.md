# 条码生成器 (Batch Barcode Generator)

纯前端、零依赖的单文件工具，用于批量生成条码并导出为图片。

> 视觉风格遵循根目录 [`../../design.md`](../../design.md) 规范（Next.js 默认风格：浅色/暗色双主题、**Geist 字体**、近黑前景 `#171717`、`#0070f3` 蓝色仅用于链接、黑底胶囊主按钮 + 灰边次按钮、细边框卡片；右上角主题切换按钮自动跟随系统并可手动覆盖）。

## 功能特性

- **批量录入**：支持每行一个，或用逗号 `,`、分号 `;`、空格、制表符 `\t` 混合分隔。
- **多格式支持**：CODE128 / CODE128A/B/C、EAN-13、EAN-8、UPC-A、ITF-14、CODE39、CODE93、Codabar。
- **自动识别格式**：开启后根据内容长度/数字特征自动匹配（13 位数字→EAN13，12 位→UPC，8 位→EAN8，14 位→ITF14，超长纯数字→CODE128C）。
- **可调参数**：条码高度（30–200）、是否显示条码数字文字。
- **预览与校验**：网格化预览，实时统计「总数 / 有效 / 无效」，无效项单独标记。
- **导出**：单个条码下载 PNG，或全部打包为 ZIP（文件名按条码值命名，特殊字符自动替换为 `_`）。
- **暗色模式**：默认跟随系统 `prefers-color-scheme`，右上角 🌙/☀️ 按钮可手动切换并记忆偏好（localStorage）。

## 技术实现

| 项目 | 说明 |
| --- | --- |
| 入口 | `index.html`（直接双击用浏览器打开即可，无需服务器/构建） |
| 条码渲染 | [JsBarcode](https://github.com/lindell/JsBarcode) `3.11.6`（jsDelivr CDN） |
| 打包下载 | [JSZip](https://stuk.github.io/jszip/) `3.10.1`（jsDelivr CDN） |
| 导出格式 | SVG → Canvas → PNG（含白底），ZIP 用 base64 写入 |

> 依赖通过 CDN 加载，首次使用需联网。

## 使用方式

1. 浏览器打开 `barcode/index.html`。
2. 在文本框粘贴/输入条码内容。
3. 选择条码类型与参数（或保持「自动识别」）。
4. 点击 **⚡ 生成条码** → 预览区出现条码。
5. 点 **📥 一键保存全部** 打包下载，或逐张下载 / 删除。
