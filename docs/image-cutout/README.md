# 图片抠图 (Image Cutout)

纯前端的单文件抠图工具：自动识别画面边缘的主色作为背景色，一键把背景变透明、只留干净主体，容差 / 羽化 / 蒙版平滑可调，还提供橡皮擦与恢复笔刷手动修整，最终导出透明 PNG（或指定背景色的 JPG / WebP）。

> 视觉风格遵循根目录 [`../../design.md`](../../design.md) 规范（Next.js 默认风格：近黑前景 `#171717`、纯白底 + 细灰边框 `#eaeaea`、`#0070f3` 蓝色仅用于链接与聚焦环、黑底胶囊主按钮 + 灰边次按钮；浅色/暗色双主题，右上角主题切换按钮自动跟随系统并可手动覆盖）。

## 功能

- **自动去背**：加载图片后自动采样四条边（各取画面短边 4% 宽度的边带），按颜色量化聚类取占比最高的 1–3 个主色作为背景色，逐像素计算颜色距离生成 alpha 蒙版。
- **连通性判定**：默认只去除与画面边缘连通的背景像素（从四边泛洪），因此**主体内部与背景同色的区域会被保留**（如白底产品图中主体上的白色高光块、甜甜圈中间的空洞外的白色细节）；可关闭以获得"全图同色一律去除"的效果。
- **边缘羽化**：颜色距离在「容差 ~ 容差 + 羽化带」之间的像素得到 0–255 的渐变 alpha，边缘不出现硬锯齿。
- **去色边（unspill）**：对半透明边缘像素按 `C = (C - (1-a)·B) / a` 反解颜色，消掉白底图常见的白色描边、绿幕常见的绿色溢出。
- **蒙版平滑**：可选的 3×3 均值模糊，进一步柔和边缘（极值收敛回 0 / 255，避免整片半透明噪点）。
- **手动修整**：
  - **擦除背景**笔刷——刷掉自动去背后残留的色块、阴影、杂物；
  - **恢复主体**笔刷——把误删的主体部分刷回来；
  - 笔刷大小 5–400 px，按笔画撤销 / 重做（最多 40 步），可一键重置蒙版。
- **参数与手动修整互不冲突**：参数调整只重算自动蒙版，手动笔触以独立 delta 层叠加，调整容差后笔触依然保留。
- **吸管取色**：背景复杂 / 渐变时点一下背景区域即可指定背景色。
- **实时预览**：棋盘格即透明区域，所见即所得；「按住看原图」可对比。
- **导出**：PNG（透明）/ JPEG / WebP，背景可选透明 / 白 / 黑 / 自定义色，JPEG 与 WebP 可调质量；导出分辨率 = 原图分辨率，不受预览缩放影响。
- **本地处理**：所有运算在浏览器内完成，图片不上传服务器。

## 用法

直接用浏览器打开 `image-cutout/index.html` 即可，无需安装、无需服务器。

1. 添加图片（点击 / 拖拽 / `Ctrl+V` 粘贴），工具会自动检测背景色并去背。
2. 看预览：棋盘格即为被去掉的背景。若不满意，先调「颜色容差」（阈值越大去除越多）与「边缘羽化」。
3. 背景色检测不准时点「吸管取色」，在画面上点一下真实背景区域，立即重新去背。
4. 仍有残留或误删，用「擦除背景 / 恢复主体」笔刷手动补几笔，`[` `]` 调笔刷、`Ctrl+Z` 撤销。
5. 选择输出格式与背景，点「下载图片」导出（文件名形如 `photo_cutout.png`）。

快捷键：`[` `]` 调笔刷大小、`E` 切擦除、`R` 切恢复、`Ctrl/Cmd+Z` 撤销、`Ctrl/Cmd+Shift+Z` 重做。

## 依赖

无外部依赖，纯 Canvas API 原生实现（`getImageData` / `putImageData` / `drawImage` / `toBlob`），离线可用（字体回退系统字体）。

## 实现说明

三层数据结构（均为原图像素尺寸的 typed array，保证导出为原图分辨率）：

| 层 | 类型 | 含义 |
| --- | --- | --- |
| `autoMask` | `Uint8Array(W*H)` | 自动算法算出的 alpha（0–255） |
| `delta` | `Int8Array(W*H)` | 手动修整：`-1` 强制背景、`0` 未改、`1` 强制主体 |
| `mask` | `Uint8Array(W*H)` | 最终 alpha = `delta` 优先，否则取 `autoMask` |

- **背景采样**：四条边带各按步长抽样（总采样量控制在约 4 万像素内），颜色量化到 4 bit/通道后分桶统计，取计数最高的 1–3 桶的平均色；桶占比即 UI 上的「边缘占比」。
- **颜色距离**：RGB 欧氏距离归一化到 0–255（`√(dr²+dg²+db²)/√3`），对多背景色取最小值。
- **alpha 映射**：`d ≤ t` → 0；`d ≥ t + soft` → 255；中间线性过渡，`soft = 羽化 × 2.5 + 1`。
- **连通性泛洪**：以 alpha < 250 的像素为候选，从四边种子出发做 4 邻接 BFS（`Uint8Array` visited + `Int32Array` 队列，入队即标记，队列上限 = 像素数），未被访问到的候选像素（主体内部孤岛）回填 255。像素数超过 1200 万时自动跳过该步（内存与耗时保护）。
- **合成与去色边**：`out.a = src.a × mask / 255`；`mask < 255` 且 `mask > 25` 时对 RGB 做 `(C - (1-a)B)/a` 反解并 clamp。
- **局部刷新**：笔刷只重算笔刷包围盒内的 mask / 合成像素，再用 `putImageData(imgData, 0, 0, x, y, w, h)` 的脏矩形参数局部写回，最后整图 `drawImage` 缩放到预览画布，因此拖笔流畅。
- **撤销记录**：以 32×32 瓦片为单位，仅在瓦片首次被本次笔画修改时拷贝一份 `delta` 前像；撤销即回写前像并局部重算 mask / 合成，重做则按记录的笔迹点序列重放笔画。「去除占比」计数在笔刷中增量维护，撤销 / 重做 / 自动去背后整体重算。
- **渲染调度**：笔迹移动走 `requestAnimationFrame` 合并，连续拖动一笔只渲染一帧。
- **限制**：算法基于颜色相似度，适合**纯色 / 近纯色 / 简单渐变背景**（电商白底图、证件照、商品图、截图、绿幕蓝幕）；背景与主体颜色接近、毛发 / 半透明物体（玻璃、烟雾、发丝）等场景需要 AI 分割模型，本工具只能给出近似结果，可用手动笔刷修补。
