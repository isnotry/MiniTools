# 表格合并工具 (Table Merge)

纯前端的单文件工具：上传两张表格（xlsx / xls / csv），勾选匹配字段，按连接模式合并数据，结果可导出为 xlsx。

> 视觉风格遵循根目录 [`../../design.md`](../../design.md) 规范（Next.js 默认风格：**Geist 字体**、近黑前景 `#171717`、纯白底 + 细灰边框 `#eaeaea`、`#0070f3` 蓝色仅用于链接与聚焦环、黑底胶囊主按钮 + 灰边次按钮；浅色/暗色双主题，右上角主题切换按钮自动跟随系统并可手动覆盖）。

## 功能

- **双表上传**：左右两栏各上传一张表格，支持点击选择或拖拽导入，上传后即时预览前 100 行。
- **字段勾选**：分别勾选左 / 右侧参与匹配的字段（支持全选 / 取消），多字段联合作为匹配键（大小写不敏感、去空格）。
- **四种连接模式**：
  - **全连接**（默认）：保留两侧全部数据，匹配行合并、非匹配行单侧保留。
  - **内连接**：只保留两侧能匹配上的行。
  - **左连接**：保留左侧全部行，右侧无匹配则留空。
  - **右连接**：保留右侧全部行，左侧无匹配则留空。
- **同名字段合并**：左 / 右两侧同名字段自动合并到同一列，优先取右侧非空值，右侧为空时保留左侧值。
- **结果导出**：合并结果一键导出为 `.xlsx`，文件名带日期（`合并结果_YYYY-MM-DD.xlsx`）。
- **统计**：显示匹配行数与总结果行数。
- **限制**：单文件 ≤ 100MB；仅读取每个工作簿的第一个 sheet。

## 用法

直接用浏览器打开 `table-merge/index.html` 即可，无需安装、无需服务器。

1. 在左 / 右两栏分别上传一张表格（`.xlsx` / `.xls` / `.csv`）。
2. 选择「合并模式」，勾选左 / 右侧作为匹配键的字段（可多选）。
3. 点击「开始合并」，下方预览合并结果与统计。
4. 点击「导出结果」下载 `.xlsx`；点「清空数据」重置全部。

## 实现说明

- 文件解析与导出全部基于 SheetJS 在浏览器本地完成，**不上传到任何服务器**。
- 匹配键由所选字段的值按顺序拼接（`|||` 分隔）后小写化生成，多行同键会展开为笛卡尔积。
- 同名字段合并策略：右侧非空优先，否则取左侧值；两侧都有的字段在结果中只保留一列。
- 预览仅展示前 100 行，导出会写出完整结果。
- 框架用 Vue 3（全局构建版），主题切换走原生 JS 增删 `<html>` 上的 `.dark` 类，与 Vue 状态互不干扰。
