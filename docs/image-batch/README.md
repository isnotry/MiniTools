# 图片批处理 (Image Batch)

纯前端的单文件批量图片处理工具：一次最多 99 张，支持格式转换（HEIC/HEIF → JPG/PNG/WebP 等）、缩放尺寸、图片压缩，实时显示每张原图大小 → 处理后大小与节省比例，结果可单张下载或打包 ZIP。

> 视觉风格遵循根目录 [`../../design.md`](../../design.md) 规范（Next.js 默认风格：**Geist 字体**、近黑前景 `#171717`、纯白底 + 细灰边框 `#eaeaea`、`#0070f3` 蓝色仅用于链接与聚焦环、黑底胶囊主按钮 + 灰边次按钮；浅色/暗色双主题，右上角主题切换按钮自动跟随系统并可手动覆盖）。

## 功能

- **批量上传**：点击选择或拖拽导入，最多 99 张，支持 HEIC / HEIF / JPG / JPEG / PNG / WebP。
- **格式转换**：输出 JPEG / PNG / WebP，HEIC/HEIF 自动解码（iPhone 实拍图可直接转通用格式）。
- **图片压缩**：可调 JPEG/WebP 质量（0.1–1.0），处理后在列表显示每张「原大小 → 新大小 + 节省%」，压缩率一目了然。
- **缩放尺寸**：可选填目标宽 / 高（像素），支持锁定宽高比例（改一个另一个自动算）；留空则保持原尺寸（仅转换格式 / 压缩）。
- **大小对比**：文件列表实时显示每张原图格式/大小/尺寸 → 处理后格式/大小/尺寸 + 节省或增大百分比；顶部汇总显示总原始大小、总处理后大小与整体节省率。
- **批量导出**：单张下载或一键打包 ZIP（重名自动加序号）。
- **本地处理**：所有运算在浏览器内完成，图片不上传服务器。
- **暗色模式**：默认跟随系统，右上角 🌙/☀️ 按钮可手动切换并记忆偏好（localStorage）。

## 用法

直接用浏览器打开 `image-batch/index.html` 即可，无需安装、无需服务器。

1. 点击或拖拽添加图片（最多 99 张），列表显示每张原图信息。
2. 设置输出格式与质量（PNG 无损时不需质量）。
3. 如需缩放，填写目标宽 / 高（可锁定比例）；留空表示不缩放。
4. 点击「开始处理」，逐张处理并显示结果与大小对比。
5. 单张点「下载」，或点「打包下载 ZIP」一次导出全部。

## 依赖

| 依赖 | 版本 | 用途 | 加载方式 |
| --- | --- | --- | --- |
| `heic2any` | 0.0.4 | HEIC/HEIF 解码为 JPEG（iPhone 实拍图输入） | CDN（`cdn.jsdelivr.net`），需联网 |
| `jszip` | 3.10.1 | 批量结果打包为 ZIP | CDN（`cdn.jsdelivr.net`），需联网 |

> 缩放 / 格式转换 / 压缩基于 Canvas API 原生实现（`drawImage` + `toBlob`），无额外依赖。HEIC 输入时先由 heic2any 转为 JPEG 中间态再走 Canvas 处理。

## 实现说明

- **HEIC 解码**：检测文件类型 / 扩展名，调用 `heic2any({ blob, toType: 'image/jpeg' })` 转 JPEG blob，再加载为 Image，后续统一走 Canvas。
- **处理引擎**：对每张图按可选目标尺寸创建 Canvas，`drawImage` 重绘（PNG 保留透明，JPEG/WebP 填白底），`toBlob(type, quality)` 得到结果 blob。
- **大小显示**：用 `blob.size` 读取处理后字节数，与 `file.size` 对比计算节省率；顶部汇总累加所有原图与结果大小。
- **ZIP 打包**：JSZip 逐个 `zip.file(name, blob)`，`generateAsync` 生成总 blob 触发下载；重名文件自动追加序号。
- **限制**：单次最多 99 张（超出截断并提示）；HEIC 解码较慢，大批量请耐心等待。
