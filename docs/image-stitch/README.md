# 图片拼图 (Image Stitch)

纯前端的单文件拼图工具：选中任意多张图片，按**数量自动等分**排布拼成一张长图 / 方图（如 5 张 → 3×2 网格），列数、单格画幅、间距、外边距、背景色与填充方式均可调，缩略图拖拽排序，一键导出高清 PNG / JPEG / WebP。

> 视觉风格遵循根目录 [`../../design.md`](../../design.md) 规范（Next.js 默认风格：近黑前景 `#171717`、纯白底 + 细灰边框 `#eaeaea`、`#0070f3` 蓝色仅用于链接与聚焦环、黑底胶囊主按钮 + 灰边次按钮；浅色/暗色双主题，右上角主题切换按钮自动跟随系统并可手动覆盖）。

## 功能

- **自动等分**：不设列数时按 `列数 = ceil(√(张数 × 单格画幅比))` 自动选网格，例如 2 张 → 2×1、3~4 张 → 2×2、5~6 张 → 3×2、7~9 张 → 3×3、10~12 张 → 4×3；也可手动指定 1–6 列。
- **末行两种排布**：
  - **拉伸填满**（默认）：末行不足时按实际张数平分整行宽度，画面无空洞（如 3 张 =「上面两张 + 下面一条横幅」）。
  - **居中留白**：末行保持与上方相同的列宽并整体居中，网格纵向对齐。
- **单格画幅**：方形 1:1、横版 4:3、宽幅 16:9、竖版 3:4、长竖 9:16——同时参与自动列数计算，宽幅自动多排横向、竖版自动多排行。
- **单图填充**：裁剪填满（cover，不变形、居中裁剪）或完整显示（contain，按比例缩放到格内、空隙露出背景色）。
- **精细可调**：图片间距 0–80 px、外边距 0–120 px、单格边长 200–1600 px（决定输出分辨率）、背景色（白 / 浅灰 / 黑 / 自定义）。
- **排序与移除**：缩略图**拖拽排序**，右上角 × 单张移除，另有「按名称排序」「反转顺序」「清空」。
- **导入方式**：点击选择、拖拽多张到上传区，或直接 `Ctrl/⌘ + V` 粘贴；支持 JPG / PNG / WebP 等浏览器可解码格式，最多 36 张。
- **导出**：PNG（无损）/ JPEG / WebP，JPEG 与 WebP 可调质量；导出分辨率 = 预览画布分辨率，所见即所得。
- **本地处理**：所有运算在浏览器内完成，图片不上传服务器。

## 用法

直接用浏览器打开 `image-stitch/index.html` 即可，无需安装、无需服务器。

1. 添加图片（点击 / 拖拽 / 粘贴），用缩略图拖拽调整顺序。
2. 保持「列数 = 自动」即可按数量等分；需要特定版式时再手动指定列数、画幅与末行排布。
3. 按需调整间距、外边距、单格边长与背景色，右侧实时预览。
4. 选择输出格式与质量，点击「下载拼图」导出（文件名形如 `collage-20260918-015856-5.png`，末尾为图片张数）。

## 依赖

无外部依赖，纯 Canvas API 原生实现（`drawImage` / `toBlob`），离线可用（字体回退系统字体）。

## 实现说明

- **单一画布**：预览 `#preview` 即导出画布（`canvas.width/height` = 目标输出分辨率），靠 CSS `max-width:100%` 缩放显示，因此「预览 = 导出结果」，不存在二次缩放误差。
- **分辨率推导**：`canvasW = cols × cellW + (cols-1) × gap + 2 × pad`，`cellW = 单格边长 × 画幅比`；高度同理由行数推导。
- **末行拉伸**：末行第 i 张的起点 `x = pad + i × (slotW + gap)`，其中 `slotW = (contentW - (k-1) × gap) / k`（k 为该行实际张数）；该行最后一张以 `pad + contentW - x` 收尾，避免四舍五入留下 1px 缝。
- **填充算法**：cover 时按目标宽高比从源图中心裁出等比矩形（`drawImage` 九参形式），contain 时按源图宽高比算出内缩矩形并居中；`imageSmoothingQuality = 'high'` 保证缩放质量。
- **渲染调度**：所有参数变更走 `requestAnimationFrame` 合并，连续拖动滑块只渲染一帧。
- **对象 URL**：每张图用 `URL.createObjectURL` 生成一个缩略图地址，移除 / 清空时 `revokeObjectURL` 释放。
- **排序**：缩略图用原生 HTML5 拖拽（`dragstart / dragover / drop`）交换数组下标后重排 DOM。
- **限制**：单张图与格子尺寸差距极大时（超宽图塞进竖格）会裁掉较多内容，此时改用「完整显示」即可；超过 36 张不接纳（拼图可读性上限）。
