# HTML 转 PDF 工具 (HTML → PDF)

纯前端的单文件工具：粘贴 / 上传 HTML，实时预览，一键导出为 PDF。

> 视觉风格遵循根目录 [`../../design.md`](../../design.md) 规范（Next.js 默认风格：**Geist 字体**、近黑前景 `#171717`、纯白底 + 细灰边框 `#eaeaea`、`#0070f3` 蓝色仅用于链接、黑底胶囊主按钮 + 灰边次按钮；浅色/暗色双主题，右上角主题切换按钮自动跟随系统并可手动覆盖）。

## 功能

- **输入 HTML**：直接粘贴源码，或「载入 HTML 文件」上传 `.html`，或「示例」一键填入。
- **实时预览**：右侧模拟纸张预览，预览宽度随页面尺寸 / 方向同步（所见即所得）；编辑停止 0.6s 自动刷新。
- **导出 PDF**：可选页面尺寸（A4 / A3 / A5 / Letter / Legal）、方向（纵向 / 横向）、边距、清晰度 `scale`(1–4)、文件名；按内容高度自动分页。
- **安全**：导出前自动去除 `<script>` 标签，仅保留版式与样式。

## 用法

直接用浏览器打开 `html-to-pdf/index.html` 即可，无需安装、无需服务器。

1. 在左侧粘贴或载入 HTML。
2. 调整页面设置（尺寸 / 方向 / 边距 / 清晰度 / 文件名）。
3. 点击「👁️ 预览」查看效果，再点「📥 转换为 PDF」下载。

| `html2pdf.js` | 0.10.1 | HTML → PDF（内部已打包 `html2canvas` + `jsPDF`） | CDN（`cdn.jsdelivr.net`），需联网 |

## 实现说明

- 基于 `html2canvas` 渲染，**导出的 PDF 中文字为图像（不可选中 / 搜索）**，适合版式截图式导出。
- 若需要可选中文字的矢量 PDF，可用浏览器「打印 → 另存为 PDF」。
