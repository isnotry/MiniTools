# JSON 格式化 (JSON Formatter)

纯前端、零依赖的单文件 JSON 处理工具：格式化 / 压缩 / 校验，支持文件载入、键排序、错误定位、复制与下载。

> 视觉风格遵循根目录 [`../../design.md`](../../design.md) 规范（Next.js 默认风格：浅色/暗色双主题、**Geist 字体**、近黑前景 `#171717`、`#0070f3` 蓝色仅用于链接、黑底胶囊主按钮 + 灰边次按钮、细边框卡片；右上角主题切换按钮自动跟随系统并可手动覆盖）。

## 功能特性

- **格式化 / 压缩**：缩进可选 2 空格 / 4 空格 / Tab；可开启按字母排序键。
- **实时校验**：输入防抖自动校验，非法时显示「第 X 行第 Y 列附近」错误定位。
- **文件载入**：通过 `载入 JSON 文件` 直接读取本地 `.json` / 文本文件。
- **示例 / 清空**：一键载入示例数据或清空输入。
- **复制 / 下载**：结果可复制到剪贴板或下载为 `formatted.json`。
- **元数据**：实时统计输出大小与行数。
- **暗色模式**：默认跟随系统，右上角 🌙/☀️ 按钮可手动切换并记忆偏好（localStorage）。

## 技术实现

| 项目 | 说明 |
| --- | --- |
| 入口 | `index.html`（浏览器直接打开，无需服务器/构建） |
| 依赖 | 无（纯原生 JS） |
| 逻辑 | `JSON.parse` / `JSON.stringify` + 自定义排序 replacer + 错误位置解析 |
