MiniTools

一组单文件前端小工具 · 双击即用，无需安装

图片裁切

网格等分切图、智能切图、智能裁剪、选框裁切，打包 ZIP，本地处理。

图片批处理

批量格式转换（HEIC/JPG/PNG/WebP）、缩放、压缩，显示原大小→新大小，最多 99 张。

JSON 格式化

校验 / 格式化 / 压缩 JSON，自动定位错误行列，支持排序与下载。

流程图编辑器

基于 Mermaid.js 的图表编辑器，实时预览，可导出 PNG / SVG。

HTML 转 PDF

粘贴或上传 HTML，实时预览后一键导出 PDF，支持页面尺寸与边距。

表格合并

上传两张表格，勾选匹配字段，按全 / 内 / 左 / 右连接合并，导出 xlsx。

图片加水印

文字 / 图片水印平铺 / 定位，透明度、大小、旋转、间距可调，实时预览，本地处理。

图片涂抹打码

鼠标涂抹局部马赛克 / 模糊 / 纯色遮挡，笔刷与颗粒可调，支持撤销重做，本地处理。

图片拼图

多张图片按数量自动等分排布拼成一张，列数 / 画幅 / 间距 / 背景可调，导出高清拼图。

图片抠图

自动识别背景色一键去背，容差 / 羽化可调，橡皮擦手动修整，导出透明 PNG，本地处理。

条码生成器

批量生成一维条码（JsBarcode），支持导出 PNG / 打包 ZIP 下载。
