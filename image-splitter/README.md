# 图片裁切 (Image Splitter)

纯前端、零依赖的单文件图片处理工具：选一张图片，按网格等分切图（打包 ZIP）、智能切图、智能裁剪或选框裁切，全部在浏览器本地完成。

> 视觉风格遵循 [`../docs/design.md`](../docs/design.md) 规范（Next.js 默认风格：**Geist 字体**、近黑前景 `#171717`、纯白底 + 细灰边框 `#eaeaea`、`#0070f3` 蓝色仅用于链接与聚焦环、黑底胶囊主按钮 + 灰边次按钮；浅色/暗色双主题，右上角主题切换按钮自动跟随系统并可手动覆盖）。

## 功能

- **四种处理模式**：
  - **网格切图**：按「列 × 行」等分图片，适合规则棋盘格切割。
  - **智能切图**：自动检测内容边界按空白区域切分，可调「检测灵敏度（高/中/低）」「合并间隙（像素）」「检测方向（横向 / 纵向 / 行+列网格）」。
  - **智能裁剪**：按目标比例自动裁剪，内置 1:1、16:9、4:3、3:2、2:1、9:16，支持自定义宽高比（基于 smartcrop 算法：边缘检测 + 饱和度 + 三分构图法）。
  - **选框裁切**：在预览图上用鼠标拖拽框选任意矩形区域，自由裁切（选区外半透明遮罩，松开鼠标可重新拖拽调整）。
- **输出格式**：PNG（无损）/ JPEG / WebP，可调 JPEG/WebP 质量。
- **本地处理**：所有运算在浏览器内完成，图片不上传服务器。
- **批量导出**：切图结果打包为 ZIP 下载。
- **暗色模式**：默认跟随系统，右上角 🌙/☀️ 按钮可手动切换并记忆偏好（localStorage）。

## 用法

直接用浏览器打开 `image-splitter/index.html` 即可，无需安装、无需服务器。

1. 点击「选择图片」或拖拽上传一张图片。
2. 在「① 选择图片」下方切换处理模式（网格切图 / 智能切图 / 智能裁剪 / 选框裁切）。
3. 按模式设置参数（切分格式、灵敏度、目标比例等；选框裁切模式下直接在预览图上拖拽框选）。
4. 选择输出格式与质量。
5. 点击「切图并下载 / 智能切图 / 智能裁剪 / 裁切并下载」导出，或「清空」重置。

| `jszip` | 3.10.1 | 切图结果打包为 ZIP | CDN（`cdn.jsdelivr.net`），需联网 |

> 图片处理（切图 / 裁剪 / 格式转换）基于 Canvas API 原生实现，无额外依赖。

## 实现说明

- 网格切图：按 `列 × 行` 在 Canvas 上计算每块区域，逐块 `toBlob` 导出。
- 智能切图：扫描像素行/列的亮度方差判定空白边界，按灵敏度阈值切分；可合并相邻小间隙。
- 智能裁剪：降采样后计算显著度图（Laplacian 边缘 + HSL 饱和度），滑窗搜索 + 三分构图法权重找最佳裁剪框。
- 选框裁切：监听预览 canvas 的 mousedown/mousemove/mouseup，实时绘制选区遮罩；松开时把 canvas 坐标换算为原图坐标，导出时按选区 `drawImage` 裁切。
- 输出统一走 Canvas `toBlob`，ZIP 由 JSZip 在内存中打包后触发下载。
