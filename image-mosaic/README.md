# 图片涂抹打码 (Image Mosaic)

纯前端的单文件图片打码工具：在画面上按住鼠标拖动即可局部涂抹，支持 **马赛克 / 模糊 / 纯色遮挡** 三种方式，笔刷大小与颗粒粗细可调，带撤销 / 重做 / 还原 / 按住对比原图，导出分辨率与原图完全一致。

> 视觉风格遵循 [`../docs/design.md`](../docs/design.md) 规范（Next.js 默认风格：**Geist 字体**、近黑前景 `#171717`、纯白底 + 细灰边框 `#eaeaea`、`#0070f3` 蓝色仅用于链接与聚焦环、黑底胶囊主按钮 + 灰边次按钮；浅色/暗色双主题，右上角主题切换按钮自动跟随系统并可手动覆盖）。

## 功能

- **涂抹打码**：鼠标（或触屏 / 触控笔）按住拖动即涂抹，笔刷为圆形，拖动路径自动插值补点，不会出现断点。
- **三种方式**：
  - **马赛克**：按颗粒网格取块内平均色填充，颗粒 4–60 px 可调。
  - **模糊**：降采样 + 升采样实现盒式模糊，强度 4–80 可调。
  - **纯色**：纯色块直接覆盖，内置黑 / 白 / 灰快捷色，也可自定义。
- **参数自适应**：导入图片后按尺寸自动给出合理的默认笔刷与颗粒（约 图宽/25 与 图宽/200），大图小图都好用。
- **撤销 / 重做 / 还原**：按「笔画」为单位记录（一次按下到松开 = 一步），最多保留 40 步；「全部还原」一键回到原图。
- **按住看原图**：随时对比打码前后效果。
- **快捷键**：`Ctrl/⌘ + Z` 撤销、`Ctrl/⌘ + Shift + Z`（或 `Ctrl/⌘ + Y`）重做、`[` / `]` 调整笔刷大小。
- **导入方式**：点击选择、拖拽到上传区，或直接 `Ctrl/⌘ + V` 粘贴剪贴板图片。
- **导出**：PNG（无损，保留透明）/ JPEG / WebP，JPEG 与 WebP 可调质量；输出为原图分辨率，与预览缩放无关。
- **本地处理**：所有运算在浏览器内完成，图片不上传服务器。

## 用法

直接用浏览器打开 `image-mosaic/index.html` 即可，无需安装、无需服务器。

1. 点击 / 拖拽 / 粘贴导入一张图片（单张处理，换图会重置所有涂抹）。
2. 选择涂抹方式（马赛克 / 模糊 / 纯色），拖动滑块调整画笔大小与颗粒或强度。
3. 在画面上按住鼠标拖动涂抹需要遮挡的区域，可随时撤销或按住「按住看原图」对比。
4. 选择输出格式与质量，点击「下载图片」导出。

## 依赖

无外部依赖，纯 Canvas API 原生实现（`getImageData` / `putImageData` / `drawImage` / `toBlob`），离线可用（字体回退系统字体）。

## 实现说明

- **三层画布**：
  - `srcCanvas`：原图层，只读，作为所有效果的采样源（保证重复涂抹幂等，不会「越涂越糊」）。
  - `workCanvas`：工作层，与原图同尺寸，涂抹结果累积在此，导出直接用它。
  - `viewCanvas`：预览层，原图等比缩放到最大宽 1000px，仅用于显示与坐标换算。
- **坐标换算**：通过 `getBoundingClientRect()` 把屏幕坐标映射回原图坐标，因此预览缩放、CSS 自适应都不影响涂抹位置精度。
- **按块处理**：以 `颗粒/模糊半径` 为网格把画面切成块，块中心落在笔刷圆内才处理；已处理块记录到 `processed` 集合（key 含模式与参数），同一参数重复涂抹自动跳过，不同参数可叠加覆盖。
- **性能**：每次落笔按笔刷包围盒做 **1 次 `getImageData` + 1 次 `putImageData`**，块级运算在 JS 内存里完成；`pointermove` 用 `requestAnimationFrame` 合并绘制，保证大图上拖动流畅。
- **模糊实现**：包围盒区域先降采样到 `1/k` 再放大回原尺寸（`imageSmoothingQuality: 'high'`），等效盒式模糊，比逐像素卷积快一个数量级。
- **撤销**：每笔画记录被首次修改块的「前像像素」；撤销时取笔画包围盒一次性 `getImageData`，在内存里回填所有前像后 `putImageData`，重做则按保存的采样点重放（效果幂等，重放结果一致）。
- **限制**：单张处理；超大图（如 8000px 以上）首次涂抹的包围盒较大时略有延迟，属正常现象。
